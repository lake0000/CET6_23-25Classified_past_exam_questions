# 六级真题 2023-2025 题型切分整理

本项目用于整理一份 2023-2025 年大学英语六级真题合集 PDF，并按题型拆分为更方便复习、打印和归档的独立 PDF 文件。

## 项目资源

当前目录包含：

- `六级真题合集【2023-2025一键打印版】.pdf`：原始真题合集 PDF。
- `格式.md`：根据第一套完整试卷整理出的切分规则、题型结构和页码范围。
- `split_cet6_pdf.py`：PDF 自动切分脚本。
- `切分结果/`：按题型分类后的输出文件。

`切分结果/` 下包含五个分类：

| 分类 | 文件数量 | 内容 |
|---|---:|---|
| `听力` | 11 | 各套实际给出的听力题目。部分第三套听力与前套一致，原 PDF 未重复给出，因此不生成空文件。 |
| `选词填空` | 16 | Reading Comprehension Section A，包含短文、26-35 空和词库。 |
| `长篇阅读（段落匹配）` | 16 | Reading Comprehension Section B，包含段落文章和 36-45 匹配题。 |
| `仔细阅读` | 16 | Reading Comprehension Section C，包含 Passage One、Passage Two 及 46-55 题。 |
| `翻译作文` | 18 | 合并每套试卷的 Writing 和 Translation 两部分。 |

## 切分代码原理

脚本使用 `PyMuPDF` 处理 PDF，不进行 OCR，也不重排文字。核心思路是：

1. 打开原始 PDF，按照 `格式.md` 中确认的试卷页码范围定位每一套试卷。
2. 根据六级试卷固定结构识别题型边界：
   - `Part I Writing`
   - `Part II Listening Comprehension`
   - `Part III Reading Comprehension`
   - `Section A / B / C`
   - `Part IV Translation`
3. 对有文本层的页面，优先用标题或题目关键词的坐标校准裁剪位置。
4. 对扫描页或正文文本层不完整的页面，使用同版式的相对坐标进行裁剪。
5. 将同一题型跨页裁剪块合并为新的 PDF，保持原文档的版式、字体、图片和排版效果。
6. 按题型输出到 `切分结果/` 对应子文件夹。

运行方式：

```bash
python split_cet6_pdf.py
```

运行环境：

- Python 3.12.7
- PyMuPDF
